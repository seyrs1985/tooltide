miles to kilometers Converter

Type a value in miles and get the answer in kilometers instantly — or convert the other way. The conversion uses the exact relationship 1 miles = 1.60934 kilometers, the same formula used in textbooks and engineering references.

Miles are used for road distances in the US and UK; kilometers almost everywhere else. The international mile is defined as exactly 1.609344 kilometers, so this conversion is exact.

–

How to use

  1. Type your value into the miles box — the kilometers result updates as you type.
  2. To go the other direction, type into the kilometers box instead and read the miles result.
  3. Copy the result with one tap, or scan the reference table below for common values.
Quick reference — Handy anchors: 5K run = 3.11 mi, 10K = 6.21 mi, a marathon = 26.2 mi = 42.16 km, 60 mph ≈ 97 km/h.

Frequently asked questions

How do you convert miles to kilometers?

Multiply the number of miles by 1.60934. For example, 10 miles = 16.0934 kilometers. The converter above does this for you and shows more decimal places than you will ever need.

How many kilometers are in one miles?

Exactly 1.60934 kilometers. This is a fixed definition, not an approximation, so the conversion is exact at any scale.

Is this converter accurate for professional use?

Yes — it uses full double-precision arithmetic and the official miles-to-kilometers factor, so results are reliable for schoolwork, cooking, fitness, travel and technical work.

Can I convert kilometers back to miles?

Yes. The converter is two-way: just type in the second box and the first box updates instantly with the reverse conversion.
