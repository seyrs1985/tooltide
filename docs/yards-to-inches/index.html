yards to inches Converter

Type a value in yards and get the answer in inches instantly — or convert the other way. The conversion uses the exact relationship 1 yards = 36 inches, the same formula used in textbooks and engineering references.

Fabric stores sell by the yard; pattern pieces are marked in inches. One yard is exactly 36 inches, so the math is a clean multiply by 36 - two yards of fabric is 72 inches of material.

How to use

  1. Type your value into the yards box — the inches result updates as you type.
  2. To go the other direction, type into the inches box instead and read the yards result.
  3. Copy the result with one tap, or scan the reference table below for common values.
Quick reference — Handy anchors: 1 yd = 36 in, 2 yd = 72 in (fabric length), 10 yd = 360 in, 100 yd = 3,600 in (a football field minus end zones).

Frequently asked questions

How do you convert yards to inches?

Multiply the number of yards by 36. For example, 10 yards = 360 inches. The converter above does this for you and shows more decimal places than you will ever need.

How many inches are in one yards?

Exactly 36 inches. This is a fixed definition, not an approximation, so the conversion is exact at any scale.

Is this converter accurate for professional use?

Yes — it uses full double-precision arithmetic and the official yards-to-inches factor, so results are reliable for schoolwork, cooking, fitness, travel and technical work.

Can I convert inches back to yards?

Yes. The converter is two-way: just type in the second box and the first box updates instantly with the reverse conversion.
